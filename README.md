# 📊 Business & Expense Cash Flow Tracker

![Cash Flow Tracker Dashboard](Screenshot%202026-08-09%20130910.png)

A lightweight, interactive web application built with Python and Streamlit designed to help small businesses and entrepreneurs manage income, track operating expenses, and visualize cash flow instantly.

## 🚀 Features
* **Real-time Financial Metrics:** Instantly calculates Total Income, Total Expenses, and Net Cash Flow.
* **Interactive Visualizations:** Dynamic bar charts tracking income vs. expenses and category-wise spending breakdowns.
* **Transaction Management:** Add, log, and delete transactions with custom descriptions and date tags.
* **Modern UI/UX:** Clean, responsive dark-themed dashboard interface.

## 🛠️ Tech Stack
* **Python**
* **Streamlit** (UI framework)
* **Pandas** (Data manipulation and state management)
